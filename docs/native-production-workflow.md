# FLAMORIS 2D Native — 制作の流れ

Windows x64向けの制作候補です。ZIPをすべて展開し、`Flamoris2D.exe`を起動します。
同じフォルダーにある実行環境・描画ライブラリ・素材読込機能も必要なので、exeだけを移動しないでください。
.NET、Node、MP4用のFFmpegを同梱しています。従来版のインストールやファイル関連付けは変更しません。

## 1. 素材を開く

「素材を読み込む…」からPSDまたはCutworkの`.flimg`を選びます。
続きから作る場合は「開く…」で`.fl2d`を開きます。右上の一覧でパーツを選択し、
検索欄で名前・IDを絞り込めます。表示・ロックはそれぞれ独立したボタンです。
右下の「配置・グループ」で位置、回転、拡大率、中心、親グループと並び順を編集できます。
読み込まれた原画の状態は、上の「表示する状態」で選びます。

## 2. メッシュを作る

「メッシュ」へ移り、画像のパーツを選択します。「生成」でGridまたは輪郭を試し、
プレビューを確認して適用します。輪郭はパーツの透明度を使います。
全身を一枚の画像にした素材より、制作時に分けた各パーツを選ぶと編集範囲を把握しやすくなります。

「構造」は点・辺・面を編集します。頂点を追加しただけでは画像を貼る面は増えません。
3頂点を選んで「面を作成」、辺の両端2頂点を選んで「辺を分割」を使います。
頂点を削除すると接続している面も削除されます。Shiftで複数選択できます。
「位置決め」で頂点を動かすと画像が追従します。右下では全体の移動・回転・拡大率も指定できます。
ホイールで拡縮、右ドラッグで画面移動、Escで操作取消です。

## 3. リグを作る

「リグ」では上のBone・Warp・Weightを切り替えます。

- Bone: 追加ツールで始点から終点へドラッグします。初期形状と「原画のポーズを編集」は別です。
  パーツの固定、親の変更、回転制限、左右反転、2ボーンIKを右下で設定できます。
- Warp: 格子と範囲を設定して作成します。選択パーツを格子に入れ、制御点を選択・移動します。
  親Warpを選ぶと入れ子にできます。格子の変更・リセット・削除は右下です。
- Weight: パーツとBoneを選び、全頂点を割り当てて開始します。塗る・消す、頂点ごとの数値設定、
  正規化、最大4本のBoneへの置換を使えます。色は選択Boneの影響度を表します。
  全ウェイトの解除はSkinを無効にした状態で行います。クリッピング元もここで指定します。

## 4. 変形と原画の状態を作る

「変形」で頂点を選択・ドラッグすると、BoneやWarpの後の形を補正できます。
「メッシュ」の位置決めとは別の編集で、点や面の構造を変えません。
「原画・Key State」で状態を複製し、別のポーズを作れます。
「遷移・パーツ対応」で開始原画A・終了原画Bを選び、対応するパーツと変化方法を設定します。
共通メッシュを使う場合は両端のメッシュを指定し、「対応付けピン・位置の補助」を利用できます。
対応補助は試してから適用します。診断は内容を表示し、確認済みの記録も取り消せます。

繰り返し使う変形は「アニメーション用の形状」で選択頂点の変位を設定して作成します。
同じ対象へ別の変形も追加できます。これらは次の段階で動きのキーとして利用します。

## 5. 動きを付ける

「動き」でシーケンス名、長さ（例: 8秒）、最初の原画を指定して作成します。
クリップを作り、編集するトラックの所属でそのクリップを選択します。
トラックの種類と対象を選び、チャンネル・時刻・値を指定してキーを追加します。
Bone、Warp、メッシュ変形、配置、不透明度、表示状態、重ね順、クリッピングに対応します。
カメラはシーケンス全体のトラックとして編集します。

時刻の詳細欄は120000 ticksで1秒です。8秒は960000 ticksです。
例: Boneの回転を0秒で0、8秒で0.5ラジアンにし、8秒のクリップをシーケンスへ配置します。
変形トラックでは作成した変形と強さをキーにします。
右下の配置設定で開始・終了、切り出し位置、速度の分子/分母、繰り返し、重み、レイヤーを編集します。
原画を保持する区間や遷移の区間も編集できます。

タイムラインでキー・クリップをドラッグして移動できます。拡大と横スクロールを使えます。
補間はプリセット、段階、線形、Bezierの制御値を指定できます。
遷移の時間編集は、上の「表示する状態」で遷移を選んで「動き」へ移ります。

## 6. プレビューと書き出し

「プレビュー」でシーケンスまたは遷移を選び、再生・停止、Once/Loop、時刻移動を使います。
「書き出し」でサイズ、FPS、出力先を指定し、PNG連番を出力します。
「MP4 / H.264も作成」にチェックするとMP4も作ります。PNGも保持します。
出力先は新規または空のフォルダーを使います。途中で中止すると、完成済みのPNGは残ります。
PNGは透明、MP4は黒背景です。プレビューと書き出しは同じ評価・描画を使います。

書き出しは最大4096ピクセル/辺・8294400画素、MP4は偶数サイズです。
プレビュー画像は長辺2048ピクセルまでに縮小して表示しますが、文書の座標は変わりません。
大きな素材の高倍率表示や実時間再生の体感は、実機の画像・ハードウェアで確認してください。

## 7. 保存して続ける

Ctrl+Sで保存します。「名前を付けて保存」「コピーを保存」「別バージョンを保存」も使えます。
コピー保存は現在の保存先・未保存状態を変えません。別バージョン保存は既存ファイルを上書きしません。
閉じる・開く・素材読込の前に未保存編集がある場合は、保存・破棄・取消を選びます。
保存後に閉じ、同じ`.fl2d`を開くと、素材画像・リグ・変形・動きから編集を再開できます。
Ctrl+Z / Ctrl+Yで代表的な操作を戻し・やり直しできます。テキスト欄ではテキスト編集が優先されます。

「保存・復元の設定」で自動復旧の間隔や保存数を変更できます。
復元候補では復元する・今回は復元しない・明示的に削除する操作を区別します。
「今回は復元しない」はその起動中の案内を閉じるだけです。
PSD更新は「PSDを再取込・照合…」で差分と対応を確認して適用します。
曖昧な対応は自動確定せず、適用後も素材と制作編集をUndo/Redoできます。

## 最後のWindows実機確認

自動テストとは別に、次を完成候補で確認します。

- 普段のPSD/`.flimg`から上記の一連の作業を進め、画像変形と出力を目視する。
- 100/125/150/200%のDPIと普段の画面で、点の選択、ドラッグ、文字、フォーカスを確認する。
- 明るい画像・暗い画像でメッシュやウェイトの見やすさ、再生・スクロールの操作感を確認する。
- 保存、終了、再起動、再編集と、実際の保存先でのファイル操作を確認する。

これはElectron廃止の承認ではありません。署名付きインストーラー、更新、ファイル関連付け、
ライブMCP接続の公開は別の受け入れ条件です。開発用PNG proofは通常の制作導線から外してあります。

## MCP / AI から同じ文書を編集する

1. Native版でPSD / Cutwork / .fl2dを開き、編集対象を選びます。
2. 上部の `MCP / AI` から `有効にする（読み取り専用）` または
   `有効にする（編集可）` を選びます。起動時は無効です。
3. `接続情報をコピー` を選び、ローカルで動くMCPクライアントのHTTP設定に
   貼り付けます。接続キーを含むため公開しないでください。クライアントに
   よって設定の外側の書式は異なります。URLとAuthorizationヘッダーを使います。
4. クライアントで `live.context` → `query.scene.get_tree` / `query.keyart.list` を
   読みます。2026-07-28対応クライアントはmodern discoveryを使い、旧2025世代は
   initialize経由で接続できます。
5. 編集可で `command.scene.rename_node` または `command.scene.set_transform` を
   実行します。contextのdocumentTokenとexpectedRevisionを渡します。
6. WPFの対象名・プロパティ・画像が通常の変更通知で更新されることを確認します。
7. キャンバスにフォーカスして Ctrl+Z → 変更が戻る、Ctrl+Y → 再適用を確認します。
8. Meshの頂点位置も編集し、`live.transaction` の複数変更がCtrl+Z一回で戻ること、
   WPFで変更した内容をMCP Queryで取得できることを確認します。
9. 通常の保存 → 閉じる → 再度開くで、変更と素材が残ることを確認します。
   文書を開き直すとMCPは無効になり、古い接続キーは使えません。
10. 読み取り専用で編集を拒否すること、無効化・接続キー更新・Host再起動後に
    古いキーが使えないことを確認します。

メニューには接続先と要求数・処理中の数、下部には権限状態を表示します。
要求数はメニューを開いた時に更新されます。接続人数を示す値ではありません。
編集中のrevisionが変わった場合は競合として拒否し、上書きしません。
MCPの編集許可に保存・素材取込・ファイル操作は含まれません。
リモート/LAN、ブラウザー、クラウドからの接続やstdioブリッジは今回の対象外です。
